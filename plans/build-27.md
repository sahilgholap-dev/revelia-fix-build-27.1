## 1. Overview / Goals

Build 27 is a **major accuracy + intelligence release**, shipped as **versionName 2.0.0** (do NOT interleave into the 1.2.x line). Two linked thrusts:

1. **Empirical analysis** — replace approximations and freeform vision with *structured* feature extraction for all four modalities (astrology, face, palm, numerology), so readings are accurate and **stable across repeated runs**.
2. **Fable 5 synthesis + Q&A** — synthesize the four structured feature sets with a frontier model (**Fable 5**, Opus 4.8 fallback), and add a **conversational Q&A** feature that answers follow-ups grounded in the user's full Cosmic Blueprint. Q&A depends on the empirical work — generic answers lose against ChatGPT; the multi-modal grounding is the moat.

**Model routing** (verified against the `claude-api` skill):
- Marquee reading generation (paid): **`claude-fable-5`** primary, **`claude-opus-4-8`** mandatory fallback.
- **Q&A chat (R7 v2 — SUPERSEDES the old "Haiku answers" line):** **`claude-haiku-4-5` = ROUTER/safety only** (5-label classify, never affects credits); **answers are tier-split — free → `claude-sonnet-5`, paid regular → `claude-opus-4-8` (adaptive thinking explicit), Deep Insight (any tier) → `claude-fable-5` → Opus 4.8 fallback.** Timing/reflective mode does not change the model — the Timing Engine changes the prompt contents.
- Cheap validation / free-tier reading generation: keep on a low-cost model.

Mirrors astro.com (place search OR coordinates). Also worth pairing with a birth-time-precision prompt (exact vs approximate).
