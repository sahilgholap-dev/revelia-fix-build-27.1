# Screenshot Specifications

## Overview

Detailed specifications for creating app store screenshots for Revelia.

---

## Required Sizes

### iOS App Store

**iPhone (Required):**
- **6.7" Display (iPhone 14 Pro Max, 15 Pro Max):** 1290 x 2796 pixels
- **6.5" Display (iPhone 11 Pro Max, XS Max):** 1242 x 2688 pixels

**iPad (Optional but Recommended):**
- **12.9" iPad Pro (3rd gen+):** 2048 x 2732 pixels
- **11" iPad Pro:** 1668 x 2388 pixels

**Number of screenshots:** 6-10 per device size (6 recommended)

### Google Play Store

**Phone (Required):**
- **Standard:** 1080 x 1920 pixels (16:9)
- **Tall:** 1080 x 2340 pixels (19.5:9)

**Tablet (Optional):**
- **7-inch:** 1200 x 1920 pixels
- **10-inch:** 1600 x 2560 pixels

**Number of screenshots:** 2-8 per device type (6 recommended)

## Design Guidelines

### Color Scheme

**Primary Colors:**
- Background: #0A0A0F (dark)
- Accent: #9333EA (purple)
- Secondary: #F59E0B (gold)
- Text: #FFFFFF (white)

**Gradients:**
- Purple to blue: #9333EA → #3B82F6
- Gold shimmer: #F59E0B → #FCD34D

### Typography

**Overlay Text:**
- Font: SF Pro Display (iOS) or Roboto (Android)
- Title: 48-64px, Bold
- Subtitle: 24-32px, Regular
- Body: 18-24px, Regular

**App Interface:**
- Use actual app fonts (consistent with design)

### Layout

**Text Overlay Position:**
- Top 20% of screen (safe area)
- Centered horizontally
- Leave space for status bar

**App Interface:**
- Center of screen
- Show realistic content
- Avoid lorem ipsum

### Visual Style

**Aesthetic:**
- Premium, mystical, modern
- Dark theme with gold accents
- Cosmic/celestial elements (stars, gradients)
- Clean, uncluttered

**Effects:**
- Subtle glow on text
- Gradient overlays
- Soft shadows
- Blur backgrounds slightly to highlight text

## Creation Workflow

### Option 1: Design from Scratch (Figma)

**Time:** 4-6 hours

1. **Setup:**
   - Create Figma file
   - Create frames for each size (1290x2796, 1242x2688, etc.)
   - Set up color palette and text styles

2. **Design:**
   - Design each of 6 screens
   - Add text overlays
   - Add app interface screenshots
   - Apply effects and styling

3. **Export:**
   - Export each frame as PNG
   - 2x resolution for retina displays
   - Optimize file size (<5MB per image)

4. **Review:**
   - Check on actual device if possible
   - Verify text is readable
   - Ensure consistent style

### Option 2: Screenshot + Mockup (Faster)

**Time:** 2-3 hours

1. **Capture:**
   - Take screenshots from actual app
   - Use demo account with good content
   - Capture all 6 screens

2. **Mockup:**
   - Upload to mockup generator (Previewed)
   - Choose device frame
   - Add text overlays
   - Apply background and effects

3. **Export:**
   - Download in required sizes
   - Optimize file size

4. **Review:**
   - Check quality
   - Verify text is readable

### Option 3: Hire Designer (Recommended)

**Time:** 1-2 days (designer's time)

**Cost:** $200-500

**Platforms:**
- **Fiverr** - https://fiverr.com
- **Upwork** - https://upwork.com
- **Dribbble** - https://dribbble.com/jobs

## Quality Checklist

### Before Upload

- [ ] All required sizes created
- [ ] Text is readable on small screens
- [ ] No spelling or grammar errors
- [ ] Consistent style across all screenshots
- [ ] App interface looks realistic (no placeholder text)
- [ ] Colors match brand guidelines
- [ ] File sizes under 5MB each
- [ ] PNG format (not JPEG)
- [ ] No personal/sensitive information visible
- [ ] Screenshots show actual app features
- [ ] Text overlays don't cover important UI
- [ ] Status bar is clean (full battery, good signal)

### Device Testing

- [ ] View on actual iPhone (if possible)
- [ ] View on actual Android phone (if possible)
- [ ] Check in App Store Connect preview
- [ ] Check in Play Console preview
- [ ] Get feedback from 2-3 people

## A/B Testing Strategy

### After Launch

**Test variations of:**
1. **Screenshot order** - Which screen converts best as #1?
2. **Text overlays** - Short vs. detailed descriptions
3. **Visual style** - Dark vs. light backgrounds
4. **CTA emphasis** - "Free trial" vs. "Premium features"

**Tools:**
- **SplitMetrics** - https://splitmetrics.com
- **StoreMaven** - https://storemaven.com
- **Google Play Experiments** (built-in)

**Metrics to track:**
- Impression to install conversion rate
- Screenshot view depth (how many users scroll)
- Install rate by screenshot variant

## Localization (Future)

### When to Localize Screenshots

**Localize when:**
- Expanding to non-English markets
- Conversion rate is low in specific countries
- Competitors have localized screenshots

**Languages to prioritize:**
1. Spanish (es) - Large market
2. French (fr) - High-value users
3. German (de) - High-value users

5. Chinese (zh-Hans) - Huge market
